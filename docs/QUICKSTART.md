# 快速开始

这份文档面向日常使用，尽量用最少步骤把本地相册跑起来。

## 一、最快启动方式（Windows）
1. 打开项目目录
2. 双击：`启动本地相册.bat`
3. 等待浏览器自动打开
4. 点击“选择本地照片文件夹”

如果默认端口 `8765` 已被占用，启动器会自动换端口并打开正确地址。

## 二、命令行启动方式
在项目根目录运行：

```bash
python scripts/serve_local_album.py
```

默认地址通常是：
- `http://127.0.0.1:8765/local-ig.html`

## 三、第一次使用建议
- 优先用 Chrome 或 Edge 打开
- 不要直接双击 `local-ig.html`
- 如果页面显示了兼容性提示，请按提示改用 localhost 方式打开

## 四、为什么不能直接双击 HTML？
因为 `file://` 模式下：
- 浏览器常会阻止 `showDirectoryPicker`
- 选择文件夹功能会受限
- 页面看起来能打开，但核心功能不一定能用

所以推荐的正确打开方式是：
- `启动本地相册.bat`
- 或 `python scripts/serve_local_album.py`

## 五、启动异常排查
### 1. 提示找不到 Python
请先安装 Python，并确保下列任一命令可用：
- `py -3`
- `python`

### 2. 双击 bat 后失败
现在启动器会尽量给出更清楚的错误。
优先检查：
- 是否被安全软件拦截
- Python 是否可执行
- `scripts/serve_local_album.py` 是否存在
- 是否有异常窗口 `Local IG Server`

### 3. 8765 端口被占用
现在会自动避让，不需要手工改端口。
如果依然失败，通常是系统策略或安全软件阻止监听。

### 4. 页面打开但按钮异常
先看页面顶部/欢迎页里的兼容性提示。
如果是 `file://` 打开的，请改用 bat 或 Python 脚本启动。

## 六、开发者自检
修改项目后可运行：

```bash
python3 -m unittest discover -s tests -v
```

当前测试覆盖重点包括：
- HTML 内联脚本语法
- 关键按钮 click 绑定
- 启动脚本关键行为
- 启动脚本与 Python 服务脚本的结构约束
- 兼容性 UI 是否存在

## 七、推荐维护习惯
- 先通过启动脚本验证页面是否能打开
- 再跑测试，避免改出“页面能开但按钮全失效”的问题
- 对启动逻辑、HTML 主脚本这类核心文件，改动后一定做回归验证
